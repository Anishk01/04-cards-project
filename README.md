# 🚀 Job Portal Cards UI

A modern job listing UI built using React where job cards are displayed with company info, roles, and apply buttons.

---

## 📸 Screenshot

![Project Screenshot](./screenshot.png)

---

## ✨ Features

- 📦 Dynamic job cards using props
- 🎨 Modern UI with gradient design
- 🏢 Company logos and job roles
- 💰 Salary and location display
- 🟢 Tags like Full-time, Remote
- 🔘 Apply button UI

---

## 🛠 Tech Stack

- React.js ⚛️
- JavaScript (ES6)
- HTML5
- CSS3
